## David Deslandes

My path has taken me from chemical engineering to corporate derivatives at Goldman
Sachs and now to machine learning. I'm a first-year M.S. student in Scientific
Computing at NYU Courant, studying numerical methods, probability and machine
learning, and building the ideas from class in code.

Projects here, newest first:

- **[Transformer](https://github.com/Davidndes/Transformer)** — character-level
  decoder-only transformer from scratch in PyTorch, extended with KV caching.

- **[Orderbook](https://github.com/Davidndes/Orderbook)** — limit order book in C++
  with price-time priority and partial fills.

- **[NYCTaxiFarePredictor](https://github.com/Davidndes/NYCTaxiFarePredictor)** —
  end to end in SQL, pandas and PyTorch, with the forward pass rewritten in C++ to
  check against it.
  
- **[DigitClassifier](https://github.com/Davidndes/DigitClassifier)** — CNN on MNIST,
  model and training loop written from scratch.

Each README documents what I learned and the questions I still have.
